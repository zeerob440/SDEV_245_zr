encrypt_decrypt.py is a simple symmetrical and asymmetrical encryption demonstration program. 
it used the fernet package from the Python cryptographic library to demonstrate asymmetric encryption, and the rsa library to demonstrate asymmetric encryption. 

The symmetric demonstration simply encrypted and decrypted the notorious "Hello World!" phrase using a shared key from the fernet package. I found symmetrical encryption much easier to work with than RSA encryption. 

The asymmetric encryption portion of the program used the rsa module to generate public and private keys. The public key encrypted a famous encrypted transmission from the Battle of Leyte Gulf. The message was decrypted by a private key.
